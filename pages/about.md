## De prijs

We meten de materiaalkost **M** van één product: papier, inkt en verpakking, plus 20% voor misdrukken. De verkoopprijs is altijd 7 × M. Werkuren tellen niet mee.

| | | A2 (M = € 6,00) |
|---|---|---|
| 1M: | Materiaal, voor wie het voorschoot | € 6,00 |
| 3M: | Maker, bruto auteursrecht | € 18,00 |
| | &emsp;↳ netto auteursrecht, naar de maker | € 15,30 |
| | &emsp;↳ roerende voorheffing (15%), ingehouden en doorgestort door vzw Peapickers | € 2,70 |
| 2M: | Twee mogelijke paden | € 12,00 |
| | &emsp;↳ met projectfinancierder: 2M naar de financierder, tot alles terugbetaald is | € 12,00 |
| | &emsp;↳ zonder projectfinancierder: 1M extra bruto auteursrecht voor de maker en 1M voor Peapickers | € 6,00 + € 6,00 |
| 1M: | Peapickers, vaste kosten | € 6,00 |
| **7M:** | **Verkoopprijs** | **€ 42,00** |

Deze prijsdeconstructie zie je ook per product als je erop doorklikt.

## Public Ledger

Vzw Peapickers stelt zich uniek op in de markt door onze financiële transparantie. Naast de prijsontleding delen we onze volledige boekhouding in de [public ledger]({{ "/register.html" | relative_url }}). Hier vind je een tijdslijn met alle financiële gegevens, geanonimiseerde administratieve acties (aankopen en verkopen) en de context die deze nonprofit maakt tot wat hij is.

## De maker wordt betaald in auteursrechten

Voor elk kunstwerk dat je hier kunt kopen, sluit vzw Peapickers een exploitatieovereenkomst met de maker. Zo krijgt Peapickers een licentie: eenvoudig gezegd het recht om reproducties te verkopen van de kunst die je hier ziet. Dat kan in verschillende vormen, zoals posters, textieldruk of boeken. Dankzij de auteursrechtenwetgeving krijgen de makers hun deel als particulier uitbetaald, in de vorm van auteursrechten.

## De identiteitscode

Elke poster draagt de code van zijn archiefstuk, bijvoorbeeld **ARCHIEFSTUK2026-001-01**. De code verandert nooit en wordt nooit hergebruikt. Bij elk archiefstuk zie je naast elk metadataveld het MARC21-veld waar het vandaan komt, bijvoorbeeld *Titel · 245 $a*.

## Betalen

Enkel met overschrijving: na je bestelling verschijnt een QR-code met het bedrag en een gestructureerde mededeling. Zodra de betaling binnen is, drukken we je posters.
